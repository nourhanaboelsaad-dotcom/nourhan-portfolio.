# Fatma Mostafa — Portfolio

A responsive black-and-white personal portfolio made with HTML, CSS, and Bootstrap.

## Files
- `index.html` — page content and sections
- `style.css` — styling and responsive layouts

## Preview
Open `index.html` in a browser. Bootstrap and Google Fonts are loaded from online CDNs, so an internet connection helps the design display as intended.

## Before submitting
1. Replace `your.email@example.com` with your real contact email, or remove the contact link if you prefer not to publish an email.
2. Check that every skill accurately reflects your current level.
3. Replace the practice-concept project descriptions with work you have actually completed, or keep them clearly labeled as practice concepts.
4. Upload both files to your GitHub repository.
5. Since the assignment requests a private repository, make sure your instructor has access to it before submitting the link.
